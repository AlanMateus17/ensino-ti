# Ensino de TI — Alan Mateus

Repositório único com todo o material didático que uso em sala de aula, e meus estudos pessoais de Matemática e Física — organizado por curso/livro, série/parte e matéria.

## Estrutura

```
ensino-ti/
├── tecnico-em-informatica/                    → Curso Técnico em Informática (16 componentes)
├── tecnico-em-desenvolvimento-de-sistemas/    → Curso Técnico em Desenvolvimento de Sistemas (13 componentes)
├── matematica/
│   ├── matematica-basica/                     → Victor H. S. Lins, 10 partes
│   └── calculo/                               → Victor H. S. Lins, 4 volumes (Cálculo 1 ao 4)
└── fisica/
    └── termodinamica-classica/                → livro a definir
```

Cada matéria/parte/volume tem sua própria pasta com README e subpastas prontas pra apostilas, exercícios/anotações e avaliações.
