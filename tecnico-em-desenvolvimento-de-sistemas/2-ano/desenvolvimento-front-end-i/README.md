# Desenvolvimento Front-End I

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 2º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Desenvolver páginas para internet, utilizando linguagem de marcação de texto e aplicando formatação em folhas de estilo.

## Objetivos de aprendizagem específicos
HyperText Markup Language (HTML) — versões em uso da linguagem; Os novos elementos e a semântica do HTML5; Elementos do cabeçalho; Elementos estruturais; Textos; Listas; Conteúdo embutido (imagens e multimídia); Formulários; Uso de scripts; Adequação e otimização para sites de busca; Acessibilidade; Cascading Style Sheets (CSS) — versões da linguagem; CSS3; Folhas de estilo: interno e externo; Tipos de mídia; Seletores e atributos: ID, classes, TAGs e composições; Unidades de medidas; Div e span; Modelo de caixa; Flutuação e posicionamento de elementos (Position); Layout fixo e elástico; Compatibilidade entre navegadores; Seletores; Efeitos de texto e imagem.

## Recursos instrucionais sugeridos
Quadro branco, computador, projetor multimídia. Laboratório de informática. Software básico: bloco de notas e Notepad++.

## Referencial bibliográfico básico
HTML e CSS: Projete e Construa Websites - Jon Duckett - 1ª edição - Editora Alta Books - ISBN 9788576089391 - Ano 2016

## Referencial bibliográfico complementar
Use a Cabeça! HTML e CSS - Eric Freeman, Elisabeth Robson - 1ª edição - Editora Alta Books - ISBN 9788576089391 - Ano 2015
