# Matemática Discreta

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 2º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Utilizar os comandos básicos de ferramentas de computação numérica; Compreender modelos matemáticos para buscar soluções em problemas computacionais.

## Objetivos de aprendizagem específicos
Ferramenta de computação numérica: comandos básicos e implementação computacional; Cálculo numérico e análise numérica; Noções sobre erros; Zeros de funções algébricas; Solução numérica de sistemas de equações lineares e não lineares; Interpolação polinomial; Noções de séries e transformadas; Integração numérica; Solução numérica de equações diferenciais ordinárias; Conceitos de pesquisa operacional.

## Recursos instrucionais sugeridos
Quadro branco, computador, projetor multimídia.

## Referencial bibliográfico básico
Fundamentos Matemáticos para a Ciência da Computação: Matemática Discreta e Suas Aplicações - Judith L. Gersting - 7ª edição - Editora LTC - ISBN 9788521632597 - Ano 2016

## Referencial bibliográfico complementar
Matemática Discreta: Uma Introdução - Edward Scheinerman - 3ª edição - Editora Cengage - ISBN 9788522125340 - Ano 2016
