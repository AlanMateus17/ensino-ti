# Arquitetura de Sistemas

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 2º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Identificar requisitos de usuários e sistemas; Elaborar protótipo de projeto conforme necessidades apresentadas.

## Objetivos de aprendizagem específicos
Introdução e conceitos de análise de sistemas e projetos; Modelos de ciclo de vida de sistema; Estudo de viabilidade; Especificação de requisitos; Estudo de cenários e a utilização de casos de uso relativos ao negócio do cliente; Introdução aos processos de software.

## Recursos instrucionais sugeridos
Quadro branco, computador, projetor multimídia. Laboratório de informática. Software básico: Dia; ArgoUML e DBDesigner.

## Referencial bibliográfico básico
Arquitetura Limpa: o Guia do Artesão Para Estrutura e Design de Software - Robert C. Martin, Kevlin Henney - 1ª edição - Editora Alta Books - ISBN 9788550804606 - Ano 2019

## Referencial bibliográfico complementar
Análise e Projeto de Sistemas - Alan Dennis, Barbara Haley, Roberta M. Roth - 5ª edição - Editora LTC - ISBN 9788521625094 - Ano 2014
