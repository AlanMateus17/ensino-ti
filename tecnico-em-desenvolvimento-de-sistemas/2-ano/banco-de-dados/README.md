# Banco de Dados

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 2º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Modelar, implementar e manter banco de dados.

## Objetivos de aprendizagem específicos
Conceitos e tipos de bancos de dados: hierárquico, relacional, orientado a objetos, georreferenciado, NoSQL; Modelagem conceitual do banco de dados; Técnicas de levantamento de dados; Levantamento e especificação de requisitos; Dicionário de dados; Integridade referencial; Arquitetura de arquivos de dados; Teoria dos conjuntos; Tipos de dados; Normalização (Formas Normais); Implantação, instalação e manutenção de Sistema Gerenciador de Banco de Dados (SGBD); Noções de Big Data.

## Recursos instrucionais sugeridos
Quadro branco, computador, projetor multimídia. Laboratório de informática. Software básico: MySQL WorkBench, Wamp, Xampp, PHP MyAdmin, SGBD MySQL.

## Referencial bibliográfico básico
Sistema de Banco de Dados - Abraham Silberschatz, S. Korth, Henry F., Sudarshan - 7ª edição - Editora Gen LTC - ISBN 9788595157330 - Ano 2020

## Referencial bibliográfico complementar
Banco De Dados - Projetos E Implementação - Machado, Felipe Nery Rodrigues - 4ª edição - Editora Erica - ISBN 9788536532684 - Ano 2020
