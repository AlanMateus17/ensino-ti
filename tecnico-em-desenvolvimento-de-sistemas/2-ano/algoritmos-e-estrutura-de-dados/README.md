# Algoritmos e Estrutura de Dados

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 2º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Elaborar algoritmos por meio da divisão modular e refinamentos sucessivos; Compreender, codificar e manipular estruturas de dados.

## Objetivos de aprendizagem específicos
Conceito de algoritmo; Representações visuais de algoritmos, português estruturado ou linguagem algorítmica; Conceitos básicos: estruturas primitivas, variáveis, entradas e saídas; controle de fluxo; procedimentos e funções; Apontadores; Alocação estática e dinâmica de memória; Tipos abstratos de dados; Estruturas de dados lineares: listas e filas; Métodos de pesquisa e classificação de dados.

## Recursos instrucionais sugeridos
Quadro Branco / Projetor Multimídia / Laboratório de Informática. Software básico: Code::Blocks, Dev C++. Software complementar: NetBeans e Visual Studio.

## Referencial bibliográfico básico
O Poder dos Algoritmos - Nybo, Erik Fontenele - 1ª edição - Editora Enlaw - ISBN 9786580484003 - Ano 2019

## Referencial bibliográfico complementar
Estrutura de Dados e Algoritmos em C++ - Drozdek - 2ª edição - Editora Cengage - ISBN 9788522125739 - Ano 2016
