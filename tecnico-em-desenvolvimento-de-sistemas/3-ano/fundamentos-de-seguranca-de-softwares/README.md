# Fundamentos de Segurança de Softwares

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 3º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Identificar ameaças à segurança da informação; Operar mecanismos de segurança da informação no desenvolvimento de sistemas.

## Objetivos de aprendizagem específicos
Conceitos de Segurança da Informação; Cartilha de Segurança para Internet; Mecanismos de Segurança; Características de segurança da informação; Fatores essenciais para o desenvolvimento de softwares seguros (métodos de transferência de arquivos, práticas seguras na codificação, revisão do código em busca de brechas de segurança, evitar vulnerabilidades externas, adotar padrões de segurança no desenvolvimento de projetos e testes exaustivos por atores externos).

## Recursos instrucionais sugeridos
Quadro Branco / Projetor Multimídia / Laboratório de Informática. Software básico (aulas práticas): VirtualBox com sistema operacional Kali Linux para testar vulnerabilidades.

## Referencial bibliográfico básico
Segurança no Software - Miguel Pupo Correia, Paulo Jorge Sousa - 2ª edição - Editora FCA - ISBN 9789727228584 - Ano 2017

## Referencial bibliográfico complementar
Fundamentos de Segurança da Informação: com Base na ISO 27001 e na ISO 27002 - Jule Hintzbergen, Kees Hintzbergen, André Smulders, Hans Baars - 1ª edição - Editora Braspor - ISBN 9788574528601 - Ano 2018
