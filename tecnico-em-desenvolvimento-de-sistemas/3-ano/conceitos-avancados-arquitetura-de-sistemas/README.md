# Conceitos Avançados em Arquitetura de Sistemas

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 3º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Aplicar modelos ágeis a projetos de software.

## Objetivos de aprendizagem específicos
Princípios e conceitos fundamentais do Processo Ágil; Características e implementação de processo ágil; Visão geral de várias opções e especificação de processos de software; Técnicas e ferramentas para especificação de processos de software.

## Recursos instrucionais sugeridos
Quadro branco, computador, projetor multimídia. Laboratório de informática. Software básico: VirtualBox, Cisco Packet Tracer.

## Referencial bibliográfico básico
Arquitetura Limpa: o Guia do Artesão Para Estrutura e Design de Software - Robert C. Martin, Kevlin Henney, Jason Gorman - 1ª edição - Editora Alta Books - ISBN 9788550804606 - Ano 2019

## Referencial bibliográfico complementar
Engenharia de Software: Uma Abordagem Profissional - Roger S. Pressman, Bruce R. Maxim, Reginaldo Arakaki, Julio Arakaki - 8ª edição - Editora AMGH - ISBN 9788580555332 - Ano 2016
