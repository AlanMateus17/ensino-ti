# Introdução à Lógica

**Curso:** Técnico em Desenvolvimento de Sistemas (EMTI)
**Ano de escolaridade:** 1º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Codificar programas, utilizando técnica de programação estruturada.

## Objetivos de aprendizagem específicos
Introdução à lógica de programação; Comandos de entrada, processamento e saída de dados; Variáveis e constantes; Expressões e operadores; Teste de mesa; Estrutura condicional simples e composta; Estrutura de repetição; Boas práticas de programação.

## Recursos instrucionais sugeridos
Quadro Branco / Projetor Multimídia / Laboratório de Informática. Software básico: VisualG.

## Referencial bibliográfico básico
Lógica de Programação e Estruturas de Dados - Sandra Puga, Gerson Rissetti - 3ª edição - Editora Pearson - ISBN 9788543019147 - Ano 2016

## Referencial bibliográfico complementar
Lógica de Programação - Aprendendo a Programar - Rubens Campos De Almeida Júnior - 1ª edição - Editora Ciência Moderna - ISBN 9788539907427 - Ano 2016
