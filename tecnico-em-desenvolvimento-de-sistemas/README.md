# Curso Técnico em Desenvolvimento de Sistemas (EMTI)

**Eixo Tecnológico:** Informação e Comunicação
**Secretaria de Estado da Educação de Minas Gerais**

13 componentes curriculares, distribuídos em 3 anos de escolaridade.

## 1º Ano
- Introdução ao Pensamento Computacional e Oportunidades de Carreira
- Introdução à Lógica

## 2º Ano
- Algoritmos e Estrutura de Dados
- Matemática Discreta
- Arquitetura de Sistemas
- Banco de Dados
- Desenvolvimento Front-End I

## 3º Ano
- Desenvolvimento Front-End II
- Conceitos Avançados em Arquitetura de Sistemas
- Desenvolvimento de Softwares
- Fundamentos de Segurança de Softwares
- Desenvolvimento Back-End
- Desenvolvimento de Aplicativos
