# Programação Web II (PHP / MySQL)

**Curso:** Técnico em Informática (EMTI)
**Ano de escolaridade:** 3º ano
**Eixo Tecnológico:** Informação e Comunicação

## Objetivo de aprendizagem geral
Desenvolver sistemas para internet utilizando persistência em banco de dados, interface com o usuário e programação em lado servidor.

## Objetivos de aprendizagem específicos
Introdução ao back-end local e remoto; Comunicação entre front e back-end: APIs web (Padrão SOAP e REST); Funções e procedimentos; Comunicação entre navegador e aplicação (formulários, sessões e cookies); Persistência em banco de dados (operações CRUD, consultas parametrizadas e prevenção de SQL Injection).

## Referencial bibliográfico básico
PHP & MySQL: Server-side Web Development - Jon Duckett - 1ª edição - Editora Wiley - ISBN 9781119149224 - Ano 2020

## Referencial bibliográfico complementar
PHP and MySQL for Dynamic Web Sites: Visual QuickPro Guide - Larry Ullman - 5ª edição - Editora Wiley - ISBN 9780134301846 - Ano 2017
