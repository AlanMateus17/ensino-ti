# Curso Técnico em Informática (EMTI)

**Eixo Tecnológico:** Informação e Comunicação
**Secretaria de Estado da Educação de Minas Gerais**

16 componentes curriculares, distribuídos em 3 anos de escolaridade.

## 1º Ano
- Informática Básica
- Lógica de Programação

## 2º Ano
- Arquitetura e Manutenção de Computadores
- HTML / CSS
- Gestão do Tempo
- Sistemas Operacionais
- P.O.O / Java
- Programação Web (JavaScript / PHP / MySQL)
- Noções de Robótica

## 3º Ano
- Rede de Computadores
- Design
- Gerenciador de Conteúdo / Banco de Dados
- Programação Web II (PHP / MySQL)
- Laboratório de Hardware
- Laboratório de Software
- Laboratório Web
